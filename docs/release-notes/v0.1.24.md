## Compute 0.1.24: set the agent's address from the page, and stack-agent 7f2942f

- **The agent's address is set on the Work page.** The Agent panel shows where
  Compute expects the stack-agent service and lets you change it: type an
  address, press **Set address**. It is registered as the shared service
  `stack-agent` (`POST /agent/address`), so it survives restarts and every
  controller agrees on it; **Reset** removes it. Without one,
  `COMPUTE_STACK_AGENT_URL` applies, then `http://127.0.0.1:8765`, and the panel
  says which. Only plain-http loopback addresses are accepted. Reachability is
  now probed with `GET /health`.
- **stack-agent moves from `e73e74a` to `7f2942f`** (66 commits): instructions
  are sent first so providers can reuse the prompt prefix; a rejected decision
  is answered again, up to two in a row (`malformed_reply_limit`); work that
  needs no test run no longer needs PAX; durable work admission and recovery.
  Compute's own tests changed in two places only: the chip-fx boundary harness
  pins `malformed_reply_limit` to 0 (its single scripted replies assert that a
  rejected capability never reaches the host), and a release-counting test waits
  for the release the environment's owner spawns instead of reading the counter
  the instant the work returns.
