## Compute 0.1.22: the release that ships 0.1.21's assets

0.1.21 was tagged but never published its distribution assets: the macOS
certification job failed, so the release had no archives and the Homebrew tap
could not sync it. 0.1.22 is 0.1.21 with that fixed.

- **macOS builds.** `compute-guest` no longer assumes Linux libc: `openpty`
  takes a mutable winsize, close-on-exec is set with `fcntl` where
  `SOCK_CLOEXEC`/`accept4` do not exist, and the in-VM `mount` calls are
  Linux-only. The guest still runs only in a Linux microVM.
- **macOS certification.** The configured-stack copy is assembled beside
  `published-stack` so `verify.mjs` finds the source tree that pins
  stack-agent.
- `service_ui` counts text in UTF-16 units and gates on AppPort's UI corpus.
